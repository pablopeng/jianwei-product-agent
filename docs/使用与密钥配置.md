# 使用与密钥配置

## 打开页面

服务已启动时，打开 http://127.0.0.1:8765 。这是当前电脑的本机地址，其他人不能用这个地址访问你的电脑。

以后重新启动：双击工程中的`start.command`；或者在工程目录运行：

```bash
.venv/bin/python run.py
```

首次从压缩包运行时，start.command会创建工程独立环境并安装requirements.txt中的依赖。终端窗口关闭或服务进程停止后，页面暂时不可访问，重新运行即可。端口被占用时可用`.venv/bin/python run.py --port 8766`，然后访问相应端口。

## 保存DeepSeek密钥：推荐页面方式

1. 在DeepSeek开放平台创建API Key：https://platform.deepseek.com/api_keys 。
2. 打开Demo，进入“配置工作台 → 模型连接”。
3. 将密钥粘贴到API Key密码输入框，点击“保存配置”。
4. 点击“测试连接”。连接成功后回到“对话体验”。

默认使用`deepseek-flash`作为对话和图片模型，可在页面修改。具体可用模型以你的DeepSeek账号为准。

密钥写入本机工程目录的`.env.local`，文件权限为仅当前系统用户读写（0600）。页面只获得“是否已配置”的状态，不会读回已保存密钥；密钥不会写入浏览器存储、会话JSON或“导出配置”文件。`.env.local`被Git和交付压缩包排除。文件保存后下一次模型调用直接生效，无需重启。

若页面提示存在环境变量覆盖，进程中的`DEEPSEEK_API_KEY`优先于文件配置。请更新对应环境变量或移除覆盖后重启服务。

## 可选：终端隐藏输入

在工程目录中运行：

```bash
.venv/bin/python setup_key.py
```

提示粘贴密钥时，输入内容不会在屏幕显示；粘贴后回车即可。不要将真实密钥作为命令行参数输入，也不必将密钥发到聊天里。

## 两个主界面

**对话体验**：选择14条真实商品之一，或新建对话并上传商品图、详情长图、TXT/Markdown/CSV/JSON/DOCX/PDF。可以先查资料、核对冲突，再生成文案，也可以只改一条卖点。右侧结果支持展开依据、复制和导出。

长图会自动拆成图片片段。PDF当前提取文字；无可提取文字的扫描PDF需将相关页作为图片上传。单批最多12个附件、前端合计20MB、单个附件12MB。视频和音频尚未接入。

14个商品样例的结构化文字、全部商品图与详情图均已就绪。详情长图已拆片，共195个可读图片片段；旧会话刷新后自动同步。你上传的新图片也可以用于模型读图。

**配置工作台**：

- 模型连接：保存密钥、选择模型、测试连接。
- Schema：编辑原始输入、第一阶段档案及第二阶段结果结构。可扩展字段、调整描述和约束；内核依赖的核心字段不能直接删除或改类型。
- Skill：修改食品饮料规则、子类策略；也可手工新建或让DeepSeek起草额外Skill。草稿需你审阅保存并启用后才生效。额外Skill与主策略一并提供给生成器，当前不是独立训练模型。
- 提示词：修改主Agent和信息整理Prompt。
- 检查与评分：运行结果的结构、引用、版本和SKU规则检查；编辑评测维度，人工填写1—5分及备注，保存并导出评分记录。

生成规则变更后旧档案与结果会失效，下轮按新规则处理；单独修改人工评分权重不让文案失效。规则配置保存在`.agent-state/config.json`，不改动原始Schema/Skill文件。界面“撤销修改”仅撤销当前未保存编辑，不删除已保存配置。

## 目前验证范围

已检查两个页面的浏览器交互、附件解析、规则保存与应用、会话隔离、密钥不回显、结果引用检查和人工评分。程序测试使用本地脚本响应，不冒充真实模型结果。

在真实密钥配置前，无法验证账号权限、余额、模型可用性、实际生成质量或费用。内置“人工设计示例”仅用于查看界面与数据合同，已明确标注，不计作模型实跑案例。

对话回复支持Markdown（标题、表格、列表、引用及代码块）与真实流式输出。可以展开处理过程查看检索、读图和核查动作，展示的是公开执行步骤，不是模型内部思维链。完整核查用批量工具，接近预算时汇总现有发现，不再只返回上限提示。

当前为本机版本，尚未部署公网分享链接。对外部署时会将服务端密钥配置迁移到托管平台的服务端环境，且把配置工作台与体验入口的访问权限分开。
