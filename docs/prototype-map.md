# 页面与交互

`/` 对话体验：新建/恢复会话、14条商品选择、上传附件、查看材料、输入要求、多轮追问、卖点依据、复制与导出。

`/settings` 配置工作台：模型连接、Schema编辑、Skill编辑/创建/起草、Prompt编辑、规则检查/人工评分/导出。

关键状态：无资料、材料就绪、上传中、模型处理中、等待用户、草稿、人工示例、草稿过期、密钥未配置、连接成功/失败、配置校验失败。

任务使用本机后台job加轮询，不阻塞页面请求。页面刷新可恢复已有会话；同进程运行中的任务可继续等待。服务重启会恢复已落盘的对话、材料和结果，不自动重放中断的模型请求。

当前体验URL为本机127.0.0.1:8765，非公网共享URL。
