# AI开发与运行约定

先阅读本目录的方案与Schema说明、dev-plan。修改Schema时同步Prompt、Skill、示例和合同校验。原始数据只读保留；临时处理放工作目录，模型会话放sessions并排除版本控制。

主Agent自主选择只读检索、整理、生成和追问；不具有对外发送、修改商家商品或发布文案的工具。正式草稿只由generate_selling_points校验通过后保存。

新增材料由可信接入层登记。对话中的事实补充只能记录用户实际原话；要求强调某属性不是该属性的证据。图片路径由服务端上传层分配，未来Web接口不能开放任意本地文件路径。

来源合同由contracts.py执行；提示词负责语义边界，两者不可互相代替。严禁将离线脚本响应描述成模型验证成功。

API密钥仅通过服务端环境变量读取，不进浏览器、不进样例、不进会话。供应商失败记录状态类别，不保存Authorization或完整原始HTTP请求。跨用户上线前补齐会话隔离、上传路径控制与请求预算。

默认每轮10批工具决策，结构化输出最多修复一次；工具调用事件仅记录名称和是否成功。会话支持恢复，但当前CLI保存为本地JSON，尚无多人服务。
