# 两个主界面的设计约定

用户要求简洁，参考即创中央输入框、附件与对话交互。采用浅色中性背景、克制紫色强调、清楚留白和原生字体。不复制灵感广场、营销横幅或复杂资产导航。

主导航只有“对话体验”和“配置工作台”。侧栏还保留新建及最近对话、模型配置状态。

对话页：空状态给出说明、三个快速真实商品入口及全部14条浏览入口。下方大输入框支持附件与拖入。对话按轮呈现，处理状态展示当前动作名称；结果出现后在右侧展示卖点、依据与详情说明。窄屏将结果放到对话下方。

配置工作台：模型连接、Schema、Skill、提示词、检查与评分为同一页面内的子分类，避免将开发配置堆到商家对话区。配置保存后真实影响后续调用。

附件、结果、密钥缺失、连接失败、配置错误、过期结果均有明确反馈。人工设计示例与真实模型输出显式区分。表单使用label，键盘可导航，输入支持中文IME与Shift+Enter换行。

本轮更新：侧栏加入收藏、置顶、归档与恢复；消息下方加入复制和最新回复重新生成。工作台Schema默认简洁示例、高级编辑按需展开。结果区仅显示卖点和优先级，主标题与详情长文不再作为本期生成结果。
