# 子类策略

| subtype | 优先解释的问题 | 证据边界 |
| --- | --- | --- |
| snack | 什么口味、包装如何、如何取用与分享 | 口感区分商家描述与评价；不凭图承诺酥脆、不腻 |
| staple_dry | 食材是什么、是否已切分、如何用于做饭 | 切丝不等于免洗/免泡；储存方法不能充当配料 |
| prepared_frozen | 是即食还是需加工、怎么准备、每份或组合是什么 | 不把需加热误写为开袋即食；时间温度只用明确说明 |
| seafood | 处理状态、规格、烹饪用途、冷冻要求 | 去皮去脏不等于无需清洗；分清净重、含冰重、头数与套装 |
| beverage_tea | 配料、产品类型、工艺、规格、冲泡或饮用建议 | 椰子水饮料不等于100%椰子水；含成分不等于减重/保健效果 |
| other / unknown | 基于明确事实生成有限结果 | 不强行套入某个子类，必要时由Agent追问 |

例：木耳丝原料明确、标题写“免切”，可提炼“预切木耳丝，做菜省去切丝步骤”，再用明确用途建议拌菜或火锅；不能补写三分钟泡发。

例：虾巴的规格列表含“不含虾”的花生瓜子巴。common模式不得写“每片有虾”；选定虾巴SKU后仍需对应原料或图文依据，不能挪用其他SKU信息。

例：麻花保留蜂蜜与花生添加比例、独立小包装，按取用便利组织表达；278g和300g未核清时省略克重，不自行选一个。
