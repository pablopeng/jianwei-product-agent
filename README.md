评测已独立为一级入口 `/evaluation`，支持通用产物标准、Agent轨迹标准、版本化执行记录、按维度统计与提示词排查建议、飞书文档导出。二期Auto Rubrics仅展示规划。详见 [评测中心设计](docs/评测中心设计.md)。

批量人工评审：选择多个Session并冻结快照，一键导出飞书电子表格，填写0/1/2下拉评分与备注后回收分析。评分留空表示未评，不计0分。完整定义与公开依据见 [通用卖点评测标准V2与批量评审](docs/通用卖点评测标准V2与批量评审.md)。
